# n2kd (NMEA 2000 daemon) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Linux daemon that reads NMEA 2000 frames from SocketCAN or a log file, decodes the PGNs the plotter needs, keeps current vessel state and an AIS target list, publishes them as newline-delimited JSON over a Unix socket, logs raw frames for later replay, and announces itself on the bus with an ISO address claim.

**Architecture:** One C++20 executable, `n2kd`, built from a static library `n2kcore` so every piece is unit-testable without hardware. Frames come from a `FrameSource` (SocketCAN or log file replay). A `FastPacketAssembler` turns multi-frame PGNs into whole payloads. A `PgnDecoder` driven by canboat's `canboat.json` turns payloads into named fields. `StateMappers` fold decoded messages into `VesselState` and `AisTargets`. A `Publisher` writes JSON snapshots to connected clients on a timer. Everything except the two I/O edges is pure and tested with Catch2.

**Tech Stack:** C++20, CMake 3.25+, Catch2 v3.16.1, nlohmann/json v3.12.0 (both via FetchContent, pinned), Linux SocketCAN, canboat `canboat.json` v9.1.0 vendored (Apache-2.0). GitHub Actions on `ubuntu-24.04` builds and tests on every push.

**Spec:** `docs/superpowers/specs/2026-10-28-cheekymarine-design.md` (sections 6.2, 6.4, 6.9, 8)

## Global Constraints

- No GPL code or assets. Dependencies here: Catch2 (BSL-1.0), nlohmann/json (MIT), canboat.json (Apache-2.0, vendored with its LICENSE and a NOTICE line). Repo license MIT.
- Listen-only on the bus except PGN 60928 ISO Address Claim (spec 6.4).
- Units are the NMEA 2000 native SI units as canboat reports them: meters, m/s, radians, kelvin, degrees for lat/lon. The app converts for display.
- Semver from the first commit: `project(CheekyMarine VERSION 0.1.0)` in the root CMakeLists is the single source; `n2kd --version` prints it.
- TDD: every task writes its failing test first. Commit after each task.
- Minimum PGNs (spec 6.4): 129025, 129026, 129029, 127250, 128267, 128259, 130310, 130311, 130316, 126992, 129038, 129039, 129794, 129809, 129810, 60928. Optional: 127488, 127489.
- Daemon must survive: malformed input, missing fields, clients disconnecting, CAN interface absent at start.

## Review Focus

Inputs the spec implies but no single feature test would exercise. Each has a test pinned to the owning task below.

1. **Garbage on the bus or in a log file** (truncated line, DLC 9, non-hex). Expected: frame skipped, counter incremented, daemon keeps running. Task 3.
2. **"Not available" field values** (0xFF, 0xFFFF, 0xFFFFFFFF, 0x7FFF signed). Expected: JSON `null`, never 655.35 m/s or 42949672 m. Task 6.
3. **GPS drops out.** Expected: position, SOG, COG become `null` within 5 s; depth keeps its own clock. Task 8.
4. **Two devices send the same fast-packet PGN at once** (two AIS sources, or a replayed log plus a live bus). Expected: assembled separately per source address, no cross-talk. Task 5.
5. **A client disconnects mid-write.** Expected: no SIGPIPE death, client dropped, others keep receiving. Task 10.

### Task 5: Fast-packet reassembly

**Files:**
- Create: `n2kd/include/n2k/FastPacket.h`, `n2kd/src/FastPacket.cpp`
- Test: `n2kd/tests/test_fastpacket.cpp`

**Interfaces:**
- Consumes: `CanFrame`, `N2kHeader`.
- Produces:
  ```cpp
  struct N2kMessage { N2kHeader header; std::vector<uint8_t> payload; double timestamp; };
  class FastPacketAssembler {
  public:
      explicit FastPacketAssembler(std::function<bool(uint32_t pgn)> isFastPacket);
      std::optional<N2kMessage> push(const CanFrame& frame); // single-frame PGNs return immediately; fast PGNs return on completion
      void expire(double now, double maxAgeSeconds = 1.0);    // drop stale partial messages
      size_t droppedIncomplete() const;
  };
  // test helper, header-only in tests/FastPacketEncoder.h:
  std::vector<CanFrame> encodeFastPacket(uint32_t canId, uint8_t seq, const std::vector<uint8_t>& payload);
  ```
  Fast-packet framing: frame 0 byte0 = (seq<<5)|0, byte1 = total length, 6 payload bytes; frame n byte0 = (seq<<5)|n, 7 payload bytes; last frame padded with 0xFF. Reassembly is keyed by (source, pgn). A frame with index 0 restarts that key. A frame whose index is not the next expected drops the partial and counts it.

### Task 6: canboat PGN database and generic field decoder

**Files:**
- Create: `third_party/canboat/canboat.json` (from `https://raw.githubusercontent.com/canboat/canboat/v9.1.0/docs/canboat.json`), `third_party/canboat/LICENSE`, `third_party/canboat/NOTICE`
- Create: `n2kd/include/n2k/PgnDatabase.h`, `n2kd/src/PgnDatabase.cpp`, `n2kd/include/n2k/PgnDecoder.h`, `n2kd/src/PgnDecoder.cpp`
- Test: `n2kd/tests/test_pgndecoder.cpp`
- Modify: `n2kd/CMakeLists.txt` to define `N2K_CANBOAT_JSON` as the absolute source path for tests, and to install the file to `share/cheekymarine/canboat.json`.

**Interfaces:**
- Consumes: `N2kMessage`.
- Produces:
  ```cpp
  struct FieldDef { std::string id; int bitOffset; int bitLength; double resolution; bool isSigned; std::string fieldType; std::optional<std::string> lookup; std::optional<double> rangeMin, rangeMax; };
  struct PgnDef { uint32_t pgn; std::string id; bool fastPacket; std::vector<FieldDef> fields; };
  class PgnDatabase {
  public:
      static std::expected<PgnDatabase, std::string> load(const std::filesystem::path& canboatJson);
      const PgnDef* find(uint32_t pgn) const;   // first definition for that PGN; nullptr if unknown
      bool isFastPacket(uint32_t pgn) const;     // unknown PGNs: true if pgn >= 0x1F000 (standard rule), else false
      std::optional<std::string> lookupName(const std::string& enumeration, int64_t value) const;
  };
  using FieldValue = std::variant<std::monostate, double, int64_t, std::string>; // monostate = not available
  struct DecodedMessage { uint32_t pgn; uint8_t source; double timestamp; std::string pgnId; std::map<std::string, FieldValue> fields; };
  class PgnDecoder {
  public:
      explicit PgnDecoder(const PgnDatabase& db);
      std::optional<DecodedMessage> decode(const N2kMessage& m) const; // nullopt for unknown PGNs
  };
  ```
  Decode rules (match canboat): bit fields are little-endian within the payload. `NUMBER`, `DATE`, `TIME`, `DURATION`, `MMSI`: raw integer read at `bitOffset`/`bitLength`, signed via two's complement when `isSigned`; value = raw * resolution as `double` (MMSI and resolution-1 integer fields are stored as `int64_t`). Not available when: unsigned raw == all ones, or signed raw == max positive, or `rangeMax` is set and value > rangeMax, or `rangeMin` is set and value < rangeMin. `LOOKUP`: `int64_t` raw, plus a second entry `<id>Name` with the enumeration name when found. `RESERVED`, `SPARE`, `BINARY`: skipped. `STRING_FIX`: bytes trimmed of trailing `0xFF`, `0x00`, `@` and spaces, as `std::string`. Any other field type: skipped. Fields past the payload end: skipped. Repeating field sets: not decoded (not needed by the spec PGNs; 129029 reference stations are after the fields we use).
