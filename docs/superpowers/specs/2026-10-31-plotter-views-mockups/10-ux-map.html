Home page

  • Tiles, 3 across, scrolls: every view (thumbnail, name, star if favourite), then + New view, then Tracks, Settings, About
  • Tap view tile: that view
  • Hold view tile: tile menu
  • Tap + New view: editor on a blank Nav view with the Setup sheet already open
  • Tap Tracks / Settings / About: that page, as today

Tile menu

  • Edit: editor
  • Favourite on/off (star)
  • Move left / Move right (tab and tile order)
  • Duplicate: copy named "<name> 2"
  • Delete: confirm; the last view cannot be deleted

Editor (one view at a time, chart live underneath)

Editor

  • The view itself, tab bar dimmed and inert
  • Chart kind: all 8 slots outlined, off ones faint with their position name; tap a slot: slot sheet; selected slot shows a corner handle, drag to resize live
  • Cells kind: cells outlined; tap a cell: cell sheet
  • Floating ⚙ Setup: Setup sheet
  • Floating Done: save, the view
  • Floating Cancel: discard changes, back to where you came from (guess: needed for a mis-tap)
→

Setup sheet

  • Name (opens keyboard), 24 max
  • Short name (keyboard), 6 max, the tab label
  • Icon: grid of about 16 bundled icons
  • Chart: Nav / Fish / None (switching to or from None swaps slots for cells; the other side's settings are kept until Done)
  • Layout (None only): opens layout gallery
  • Favourite on/off
  • Delete view
  • Done: closes the sheet, editor stays

Slot sheet (half height)

  • Show: On / Off
  • Field: Depth, SOG, STW, COG, Heading, Water temp, Position, Time, RPM
  • Size: big + and -, value in mm, 6 mm floor, ceiling = what fits (R51)
  • Sheet sits in the half away from the slot
  • Done

Cell sheet (half height)

  • Field list, same
  • Done

Layout gallery

  • 60 landscape thumbnails, scrolls, 12 mm floor
  • Tap one: cells re-flow, fields kept by cell order

Keyboard

  • Our own QML keyboard (Qt's is GPL): letters, digits, space, backspace, Done
  • 12 mm keys
